# Muerto De Hambre Grill

Custom restaurant website foundation inspired by the conversion flow of modern restaurant ordering sites while keeping Muerto De Hambre's design original.

## Current foundation

- Animated flame intro with user-triggered synthesized whoosh sound
- Responsive homepage and mobile navigation
- Animated scroll reveals and motion details
- Rialto / Lawndale Order Online selector
- Direct handoff to each location's live Otter ordering storefront
- Preferred-location memory for repeat visitors
- Homepage sections for food, story, catering, and locations
- Static-export friendly Next.js build
- Reduced-motion accessibility support

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

The temporary food/interior photography is intentionally replaceable. Add Muerto De Hambre's official logo, restaurant photography, menu content, social links, catering information, and finalized brand palette as those assets become available.
